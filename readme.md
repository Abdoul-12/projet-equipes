# 📌 Projet collaboratif GitHub

## 📖 Description du projet
Ce projet a été réalisé dans le cadre d’un travail pratique afin de mettre en place une gestion collaborative avec Git et GitHub en utilisant les branches.

---

- **Description :** Responsable de la conception de l’interface utilisateur, de la mise en forme avec HTML/CSS et de l’amélioration de l’expérience utilisateur.

### 👨‍💻 Nom du binôme
- **Rôle :** Développeur Backend
- **Description :** Responsable de la logique du projet, de la gestion des données et de l’intégration des différentes fonctionnalités.

---

## 🌿 Workflow Git
Le projet suit l’organisation suivante :

- **main** → branche principale stable
- **develop** → branche de développement par défaut
- **feature/wadoud** → branche de travail individuelle
- **feature/binome** → branche de travail du binôme

---

## 🚀 Objectif
Mettre en pratique la collaboration en équipe avec GitHub, la gestion des branches et l’organisation professionnelle d’un projet.
